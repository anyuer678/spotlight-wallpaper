把你的两张壁纸图片放进这个文件夹，按下面的名字命名即可：

  out.jpg   ← 光斑【外】的图（平时铺满桌面、你看到的那张）
  in.jpg    ← 光斑【内】的图（鼠标附近透出来的那张）

也支持 png / webp / jpeg / bmp：
  out.png、out.webp、out.jpeg、out.bmp，内层同理
命名成 outer.* / inner.* 也会被识别。

──────────── 放好之后怎么生效 ────────────

桌面版（wallpaper.pyw）：
  · 按 Ctrl + Alt + R          —— 立刻重新读取，不用重启程序
  · 或者根本不用管这个文件夹：按 Ctrl + Alt + 1 / 2
    直接用弹出来的选图框挑图，选完自动记住

网页版（index.html）：
  · 刷新页面即可。如果之前用拖拽方式设置过，浏览器本地缓存优先级更高，
    请先在设置面板里点「清空」。

──────────── 本文件夹里现在有什么 ────────────

空的 —— 仓库不附带任何图片，放你自己的两张进来即可。
放图之前程序也能跑：会先用内置渐变占位图铺满界面。

想先临时看看效果，可以拿系统自带壁纸凑一对：
  Windows\Web\Wallpaper\ThemeC\img28.jpg   白天
  Windows\Web\Wallpaper\ThemeC\img30.jpg   黄昏
同一机位的湖景，一明一暗，鼠标扫过去像"天色变了"。

──────────── 选图建议 ────────────

  · 两张图用同一构图、同一视角，切换时最震撼
  · 分辨率 ≥ 2560×1600 更稳（高分屏下光斑边缘更细腻）
    过大的图会被自动预缩，不会白占内存
  · 一亮一暗、一暖一冷，对比更明显
