聚光壁纸 · 使用说明

这是什么

屏幕上默认显示一张图；鼠标移到哪里，哪里就"透出"另一张图。鼠标附近是光斑，光斑内外各是一幅画。

换成你自己的两张图

  • 拖拽：把图片文件拖到窗口，左半屏松手 = 范围外的图，右半屏松手 = 范围内的图。也可以一次拖两张，分别放到左右。
  • 点选：面板里对应的「选择」按钮。
  • 放文件夹（推荐，可长期生效）：把图片命名成 out.jpg（范围外）和 in.jpg（范围内），放进本页面同级的 images 文件夹。支持 jpg / png / webp。
  • 图片会自动压缩到最长边 2560px 并保存在浏览器本地，下次打开还在。

快捷键

  • H 显示 / 隐藏设置面板
  • F 进入 / 退出全屏
  • 空格 暂停 / 恢复光斑跟随
  • ↑ ↓ 放大 / 缩小光斑
  • [ ] 光斑边缘更硬 / 更柔
  • Esc 关闭当前浮层

怎么真的当桌面壁纸用

  • Windows（免费）：装 Lively Wallpaper（微软商店有），把本文件 index.html 拖进去作为"网页壁纸"，鼠标穿透即可正常交互。
  • Wallpaper Engine：新建 → 网页 → 选择 index.html。
  • 最省事：双击打开本文件，按 F 全屏，三秒不动鼠标，界面会自动收起、鼠标自动隐藏。

调参建议

  • 清晰照片想要"探照灯"感：大小 300–450，边缘柔和 45%–70%。
  • 卡通 / 插画想有硬朗的边界：边缘柔和 5%–20%，光晕关掉。
  • 跟随灵敏度越小越"拖尾"，越像在水里；0.35 以上会跟手很紧。
  • 自动漂移开启后，鼠标静止 3 秒光斑会自己缓慢游走。
